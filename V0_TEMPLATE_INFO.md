# Oochi - v0 Agency Landing Page Template

**Premium agency landing page template with complete SEO, GEO, and AEO optimization.**

## 📋 Template Overview

Oochi is a professional, production-ready agency landing page template designed for design firms, creative agencies, digital strategy companies, and tech consulting services. ## 🚀 Quick Start

### Installation

```bash
# Clone or use this template
git clone <repository-url>
cd oochi

# Install dependencies
npm install
# or pnpm install / yarn install

# Start development server
npm run dev

# Build for production
npm run build
```

### Customization (30 minutes)

1. **Update Company Info** - Edit `index.html` meta tags
2. **Change Hero Text** - Update `LandingPage.jsx`
3. **Customize Colors** - Modify Tailwind classes
4. **Add Images** - Replace placeholder URLs
5. **Update FAQ** - Edit `FAQ.jsx` content

See `IMPLEMENTATION-GUIDE.md` for detailed instructions.
